# Autopilot simulations: clickable prototype

Live: https://agulati9.github.io/autopilot-simulations-prototype/
Guided tour: https://agulati9.github.io/autopilot-simulations-prototype/?tour=1 (or add `#tour` to any link)

A static, self-contained prototype for the Decagon Autopilot Simulations PRD. All data is fictional sample data.

## Update the hosted copy

1. Edit files in `src/` (`app.js`, `data.js`, `styles.css`, `template.html`; the guided tour is `src/tour.js`).
2. Run `python3 build.py`. It inlines `src/` into `index.html`. Don't hand-edit `index.html`.
3. Commit and push to `main`. GitHub Pages republishes in about a minute.
